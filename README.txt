# LILY NATY MM ACCOUNTS

A responsive Free Fire-only account marketplace.

## Included
- LILY NATY branding
- Free Fire account listing
- Available / Sold badges
- Search
- Available/Sold filters
- Account detail popup
- WhatsApp "Contact to Buy" links
- Responsive mobile design
- Five account listings are included

## IMPORTANT: Add your WhatsApp number
Open `script.js` and replace:
`2348000000000`
with your real WhatsApp number in international format, without `+`, spaces, or leading zero.

Example for a Nigerian number:
`2348012345678`

## Add another account
Copy one object in the `accounts` array in `script.js`, upload its screenshot into `assets/`, and change:
- id
- title
- price
- status
- image
- description

## Deploy
Upload the whole folder to a static hosting service such as GitHub Pages, Netlify, or Vercel.
